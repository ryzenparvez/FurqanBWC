FURQAN CLOUD - BANDWIDTH CALCULATOR
README / SETUP GUIDE
=================================

ABOUT
--------
This project is a single-page ISP bandwidth estimation calculator.


Features:
- Subscriber counts for 20, 30, 40, 50, 70, 80, 100, 150 and 200 Mbps packages
- Selectable services: IIG, Baishan, CDN, FNA, GGC and BDIX
- Optional extra bandwidth buffer percentage
- Automatic bandwidth totals and service split chart
- Light/dark theme toggle
- Copy Report and Reset controls
- Saves calculator inputs in the browser's localStorage


IMPORTANT NOTES
------------------
- The figures are estimates based on the AVG values defined in the JavaScript. They are not a guarantee of real traffic demand or a provider's required capacity.
- Verify the calculation assumptions against your actual network usage and upstream/CDN agreements before purchasing bandwidth.
- Calculator values are stored in localStorage in the current browser, not in a shared database. They do not automatically sync between devices or browsers.
- No login, server-side database, or admin panel is included in this single HTML file.
- The page uses Google Fonts from fonts.googleapis.com; if unavailable, fallback fonts are used.
- Keep a backup before editing the original file.
